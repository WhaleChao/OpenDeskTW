# 全能文件工作台 v2.8.1

本次更新修正 ONLYOFFICE 表格內的「文字等距分布」：

- 表格段落改以儲存格扣除框線、內距及段落縮排後的內容寬度計算，不再誤用整頁右界。
- 窄欄、合併儲存格與不同欄寬會各自取得動態字距，不使用固定值。
- 表格畫面不再重複套用原生分散值與備援字距，避免末字突出或整段逐字換行。
- 若桌面版 SDK 無法直接提供儲存格內寬，會以實際排版結果二分搜尋最大安全字距；只要新增換行就自動回縮。
- 儲存 DOCX 時仍保留 Word 標準 `w:jc="distribute"`，在 Microsoft Word 開啟後會按當下儲存格寬度重新排版。

驗證涵蓋一般段落、窄表格欄位、合併儲存格、壓縮版 SDK 欄位缺失，以及末字量化溢位。
