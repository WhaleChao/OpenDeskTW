# 全能文件工作台 v2.8.5

本次更新修正 ONLYOFFICE 文字等距分布在部分既有 DOCX 表格中顯示 `Cannot read properties of undefined (reading 'yBa')`：

- 對 ONLYOFFICE 9.4 壓縮版的行首／行尾內部位置呼叫加入逐行例外隔離，不讓單一失效行中止整次分散對齊。
- 精確位置不可用時，依該段落已排出的各行自然寬度分配文字邊界，仍按目前頁面、縮排及儲存格實際寬度計算動態字距，不改成固定值。
- 保留表格內寬限制與不新增換行的二分回縮，避免最後一字突出或被推到下一行。
- 診斷資料新增位置降級、位置例外、字距寫入及重排例外計數，LIVE 測試可確認功能確實套用而非略過。
- 新增單行表格與多行段落的 `yBa` 強制失敗回歸測試。

此修正不修改使用者文件內容的判斷規則；儲存時仍寫入 Word 標準 `w:jc="distribute"`，由 Microsoft Word 依實際版面重新排版。
