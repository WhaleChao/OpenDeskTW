# 全能文件工作台 v2.8.2

本次更新修正文字等距分布後的畫面抖動與輸入干擾：

- 不再於每次 `keyup` 或普通 `pointerup` 後重排所有等距段落。
- 在等距段落內新增或刪除文字時，只從目前排版扣除舊字距並一次覆寫
  目前段落的新動態字距；不會先收合再展開，也不會把新字擠到下一行。
- 按下等距按鈕後不會再被滑鼠放開事件重複執行第二次。
- 加入排版執行鎖與單次佇列，避免按鈕操作、背景刷新與寬度更新彼此重入。
- 自動刷新只保留視窗尺寸改變，以及真正拖曳欄寬、尺規或 resize 控制點後的一次延遲更新。
- 表格內按實際儲存格寬度分布、末字不突出與 DOCX 標準 `distribute` 儲存方式維持不變。

驗證包含普通鍵盤輸入後仍維持單行、普通點擊不重排、表格窄欄、
合併儲存格、欄寬拖曳與重入防護。
